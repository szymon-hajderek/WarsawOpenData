# Change notes

One file per branch, instead of a single shared `CHANGES.md`.

- When you create a branch, add a file here named after the branch, with slashes
  replaced by dashes (e.g. branch `feature/add-map` -> `changes/feature-add-map.md`).
- Briefly describe the changes made on that branch and keep it up to date.
- Because each branch owns its own file, two branches never edit the same file,
  so these notes never cause merge conflicts.
