# docs/bus-delay-ui-guide

- `artifacts/bus-delay-ui-guide.html`: guide (Polish) for the UI developer on using the `bus-delay` window event:
  when it starts and stops, fields of `BusDelayDetail`, states and proposed texts, a copyable `useBusDelay` hook,
  testing with a fake event or the real server, known gaps in `delay.ts` (fixed by PR #88).
- `artifacts/delays-report.html`: report (Polish) on the delay feature: how it works on the server, what the route list
  shows, accuracy and radius search on the 2026-10-17 recording, tests, limits, PR status (as of 2026-10-18).
- `artifacts/README.md`: rows for both pages.
